# Здоровье — интерфейс и навигация

Отдельная демонстрационная версия мобильного приложения на Flutter для первого этапа показа преподавателю. В проекте есть экран входа, главная, дневник, аналитика, профиль и переходы между четырьмя вкладками. Интерфейс русскоязычный и использует фирменные цвета и логотип основного проекта.

Показатели и продукты заданы прямо в коде как примеры. Форма входа не создаёт аккаунт. Поиск работает только по двум демонстрационным продуктам. Добавление еды, сканирование, PDF и системные переключатели показывают интерфейс, но пока не подключены к базе, API или устройству. Эти функции реализуются в [основном проекте](https://github.com/4oys/health_app).

## Запуск

```sh
flutter pub get
flutter run
```

Для проверки: `flutter analyze` и `flutter test`.

На занятии можно показать вход, все четыре вкладки, календарь, раскрытие приёмов пищи, фильтр поиска, переключение периода графика и элементы профиля. Это именно этап интерфейса: сохранение данных и интеграции относятся к следующим темам презентации.
